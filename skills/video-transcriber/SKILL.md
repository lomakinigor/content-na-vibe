# Скилл: Транскрибатор видео

## Когда использовать
Клиент говорит: «расшифруй видео», «вот моё видео/эфир», «сделай сценарий по моей записи», «переведи запись в текст», прислал видео-файл и хочет сделать по нему ролик/сценарий. Также вызывается оркестратором `producer-orchestrator`, когда клиент идёт по пути «сценарий по своему видео».

Задача: превратить видео/аудио клиента в **чистый текст**, чтобы из него собрать сценарий.

---

## Перед работой
1. Нужен ключ **`DEEPGRAM_API_KEY`**. Проверь: `printenv DEEPGRAM_API_KEY` (в терминале, значение не показывай клиенту).
2. **Если ключа нет** — не бросай клиента: дай пошаговый гайд `~/packages/content-na-vibe/keys-guide/deepgram-api-key.md` (перескажи своими словами) и точное имя переменной для `/settings → 🔑 → ✏️ Добавить свою`. Расшифровка своих видео — единственное, для чего нужен этот ключ.
3. Нужен `ffmpeg` (ставится с пакетом) — он вытаскивает звук из видео.

---

## Выполнение
Инструмент: `~/packages/content-na-vibe/tools/transcribe.py` (Deepgram nova-2, тот же движок, что в transcriber-bot). Форматы: mp4, mov, mkv, avi, webm, а также готовое аудио.

```bash
~/packages/content-na-vibe/.venv/bin/python \
  ~/packages/content-na-vibe/tools/transcribe.py "путь/к/видео.mp4" \
  -o /tmp/transcript.txt
```

- Файл видео обычно лежит в `.media/` (клиент прислал его в чат) — возьми путь оттуда.
- Скрипт сам извлечёт аудио через ffmpeg и отправит в Deepgram. Большие видео это сильно ускоряет (звук весит в разы меньше).
- Нужны таймкоды — добавь флаг `--timestamps`.

---

## Что дальше
Транскрипт `/tmp/transcript.txt` — это **вход для сценария**. Передай эстафету:
1. `scenario-writer` → соберёт сценарий из транскрипта (режим по видео) голосом клиента.
2. Дальше по обычному конвейеру оркестратора: презентация-навигатор, лид-магнит, суфлёр.

Не отдавай клиенту сырой транскрипт как результат — это промежуточный материал. Результат — готовый сценарий и файлы для съёмки.

Если Deepgram вернул ошибку авторизации (401/403) — ключ неверный или кончились кредиты, скажи клиенту прямо и предложи проверить `DEEPGRAM_API_KEY` в `/settings`.
