# Скилл: Сценарист роликов

## Когда использовать
Клиент говорит: «напиши сценарий», «сделай сценарий по теме…», «хочу записать ролик про…», «собери сценарий». Также вызывается оркестратором `producer-orchestrator` на Этапе 2 после выбора идеи.

Задача: из идеи собрать **полный сценарий ролика** голосом клиента — хук, блоки, тайминги, CTA.

---

## Перед работой
1. Прочитай голос клиента: `~/packages/content-na-vibe/voice/author-voice.md`. Пиши ЕГО тоном и оборотами. Если файла нет — попроси оркестратора провести онбординг голоса (2-3 поста клиента) или временно опирайся на эталон `~/packages/content-na-vibe/tools/scenario-kit/knowledge/writing-style.md` (это пример структуры, не стиль клиента).
2. Уточни через `AskUserQuestion`: тема/идея (обычно приходит от `trend-hunter`), примерная длительность (мин), формат (обучающий / история / разбор).

---

## Выполнение
Инструмент: `~/packages/content-na-vibe/tools/scenario-kit/`. Движок работает через Claude CLI (ключи НЕ нужны).

Сценарий по теме (с нуля — основной режим MVP):
```bash
cd ~/packages/content-na-vibe/tools/scenario-kit
~/packages/content-na-vibe/.venv/bin/python pipeline/pipeline.py --mode topic --duration 15 -o /tmp/scenario.md
```
(тему и вводные передаёшь на вход; см. `pipeline/README.md` для точного формата)

Сценарий по чужому видео (разбор донора) — режим `--mode video` из транскрипта. Скачивание чужих субтитров/расшифровка — это уже reels/transcriber (полная версия), в MVP не обязателен.

Промпты движка: `~/packages/content-na-vibe/tools/scenario-kit/prompts/`. Методология и структура: `tools/scenario-kit/knowledge/`.

---

## Результат
Готовый сценарий (`/tmp/scenario.md` или в память сессии). Обязательно: **хук в первые секунды, блоки с таймингами, конкретный CTA в конце** — голосом клиента, не placeholder.

После сценария передай эстафету оркестратору → Этап 3 (`lead-magnet-maker`), Этап 4 (`presentation-maker` — навигатор отдельным файлом) и Этап 5 (суфлёр). Каждый артефакт — отдельный настоящий файл, не склеиваем в один документ.

Не выдумывай факты по теме — если нужны данные, скажи клиенту или поищи. Голос клиента приоритетнее эталона.
