# Скилл: Сборщик презентации-навигатора

## Когда использовать
Клиент говорит: «собери презентацию», «сделай навигатор», «презентация к ролику», «нужна презентация для съёмки». Также вызывается оркестратором `producer-orchestrator` на Этапе 4 после готового сценария.

Задача: из готового сценария собрать **настоящий `navigator.html`** — веб-гид формата 1 (сайдбар-оглавление + блоки метафора/терминал/карточки), голосом клиента. Отдаётся **отдельным файлом**, не вкладкой.

---

## Перед работой
1. Нужен **готовый сценарий** (от `scenario-writer`). Если его нет — сначала он. Блоки навигатора берутся из сценария, не выдумываются.
2. Прочитай голос клиента: `~/packages/content-na-vibe/voice/author-voice.md`. Весь текст — его тоном.
3. Прочитай эталон и методичку кита:
   - `~/packages/content-na-vibe/tools/presentation-kit/navigator-template.html` — канонический эталон (копируешь `<style>` и `<script>`).
   - `~/packages/content-na-vibe/tools/presentation-kit/navigator-guide.md` — как раскладывать тему на блоки и правила.
   - `~/packages/content-na-vibe/tools/presentation-kit/CLAUDE.md` — жёсткие правила формата.

---

## Выполнение
Ты собираешь HTML **руками по образцу** — не через генератор-заглушку. Порядок:

1. Разбери сценарий на блоки (7±2), каждый = одна фишка/идея по story arc (боль → решение → доказательство → трансформация).
2. Скопируй из `navigator-template.html` блок `<style>` и `<script>` **целиком, без изменений** (дизайн-систему не переписываешь).
3. Собери сайдбар: название ролика КАПС + `@канал` клиента + список блоков (пиксельный номер + эмодзи + короткое название).
4. Для каждого блока собери `<section>` по паттерну:
   - `.block-header` — пиксельный номер + `<h2>` заголовок КАПС;
   - `.metaphor` — бытовая метафора (обязательна, голосом клиента);
   - `.terminal` — команды/действия блока (если есть; `cmd` терракот, `dim` пояснения, `kbd` клавиши);
   - `.card.pain` (боль сейчас) → `.card.win` (что получаешь) → `.card.note` (когда/нюанс).
5. Первый блок — `.intro-section` (заголовок ролика + обещание). Последний — «С чего начать» (2-3 `.card.win`).
6. Синхронизируй `id` блоков с пунктами сайдбара, иначе навигация сломается.

Сохрани в файл, например `/tmp/navigator.html` (или в папку ролика).

---

## Результат
Готовый `navigator.html` — **отдельный файл**, отправляется клиенту тегом `[ФАЙЛ: путь]`.

Самопроверка перед выдачей (чек-лист гайда):
- скопированы `<style>` и `<script>` из эталона без правок;
- у каждого блока: номер + заголовок КАПС + метафора + карточки pain/win/note;
- сайдбар совпадает с `id` блоков;
- нет open loops, таймингов, меток съёмки (это в суфлёре);
- голос клиента, а не шаблон;
- HTML открывается, подсветка сайдбара и стрелки работают.

Не выдумывай факты по теме. Голос клиента приоритетнее эталона. Реплики ведущего для чтения — не сюда, а в суфлёр (отдельный файл).
