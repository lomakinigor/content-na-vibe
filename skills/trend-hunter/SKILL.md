# Скилл: Охотник за трендами

## Когда использовать
Клиент говорит: «найди тренды», «что стреляет в нише», «какие темы залетают», «идеи по теме X», «проверь конкурента», «покажи виральные ролики». Также вызывается оркестратором `producer-orchestrator` на Этапе 1.

Задача: найти залетающие видео по теме/нише клиента и предложить **углы и хуки** для его ролика.

---

## Перед поиском — собери бриф через `AskUserQuestion`
1. **Ниша / тема** клиента (его словами: «вайбкодинг», «нутрициология», «продажи на маркетплейсах»…). НЕ подставляй чужую нишу.
2. **Формат** — длинные горизонтальные видео или Shorts. По умолчанию исключай Shorts (`--exclude-shorts`), если клиент не сказал иначе.
3. **Регион и окно** — по умолчанию RU, последние 30 дней.

> Ниша всегда от клиента. Пакет не привязан к одной теме — работает под любую нишу ученика.

---

## Выполнение
Инструмент: `~/packages/content-na-vibe/tools/trend-finder/`. Запуск через venv пакета:

```bash
cd ~/packages/content-na-vibe/tools/trend-finder
~/packages/content-na-vibe/.venv/bin/python trend_finder.py --search "ЗАПРОС КЛИЕНТА" --region RU --days 30 --min-ratio 5 --exclude-shorts
```

Проверить канал конкурента:
```bash
~/packages/content-na-vibe/.venv/bin/python trend_finder.py --channel @handle --last 30 --exclude-shorts
```

Логика виральности (ratio = просмотры / подписчики), калибровка порога, формат отчёта и все флаги — в родной документации инструмента: `~/packages/content-na-vibe/tools/trend-finder/SKILL.md` и `README.md`. Следуй ей.

## Если нет ключа YOUTUBE_API_KEY — не бросай клиента
Тренд-файндер требует `YOUTUBE_API_KEY` (ставится при установке пакета). Если инструмент падает с ошибкой ключа / переменной нет в окружении — **напечатай клиенту прямо в чат пошаговый гайд** (возьми из `~/packages/content-na-vibe/keys-guide/youtube-api-key.md`), обязательно с:
- точным **именем переменной**: `YOUTUBE_API_KEY`;
- кликабельными ссылками (создать проект → включить YouTube Data API v3 → создать ключ);
- как добавить: **`/settings → 🔑 → ✏️ Добавить свою`**, имя `YOUTUBE_API_KEY`, значение — сам ключ. **Ключ в чат не присылать.**
- нюансы: бесплатная квота 10 000/сутки хватает; экран согласия OAuth не нужен; карту привязывать не надо.

Заверши так: «Как добавишь — скажи, сразу прогоню тренд-файндер на твоей теме». После добавления ключа переменная появится в окружении агента — повтори запуск.

## После отчёта — обязательный мост
Не заканчивай на списке видео. Через `AskUserQuestion` предложи **3-5 углов/хуков** для ролика клиента по самым виральным темам и спроси, какую идею развиваем. Выбранную идею передай оркестратору → скилл `scenario-writer`.

Цифры бери только из реального отчёта инструмента — не выдумывай просмотры и ratio.
