# Обновление пакета

## Цель

Обновлять опубликованные файлы пакета из `lomakinigor/content-na-vibe`, не затрагивая данные конкретного сервера.

## Границы

Скрипт обновляет manifest, документацию, `skills/`, `tools/`, `_playbooks/`, `keys-guide/` и зависимости. Он не копирует и не удаляет `voice/`, `.venv` или `.env`.

## Проверка

Перед копированием скрипт проверяет manifest донора и наличие всех шести producer skills. Неудачная проверка останавливает обновление до изменений.
