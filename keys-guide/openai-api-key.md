# Как получить ключ OpenAI (необязательный)

Этот ключ нужен, только если хочешь, чтобы агент **расшифровывал твои записи** (аудио/видео → текст, через Whisper) и **причёсывал чужие транскрипты**. Без него всё остальное — тренды, сценарии, лид-магниты, презентации — работает.

В отличие от YouTube, OpenAI платный по факту использования (пополняешь баланс, тратится по чуть-чуть за расшифровку). Расшифровка стоит копейки, но карта нужна.

---

## По шагам

**1. Зарегистрируйся**
Перейди на [platform.openai.com](https://platform.openai.com) и войди/зарегистрируйся.

**2. Пополни баланс (минимум)**
Слева меню → **Billing / «Оплата»** → **Add payment method** (привяжи карту) → пополни на небольшую сумму (например, 5$). Этого хватит надолго.

> Если российская карта не проходит — этот ключ можно пропустить. Тренды и сценарии работают без него.

**3. Создай ключ**
Слева → **API keys** → **+ Create new secret key**. Назови (например, «контент») → **Create**.
Ключ выглядит так: `sk-...` — длинная строка.

**4. Скопируй сразу**
OpenAI показывает секретный ключ **только один раз**. Скопируй его сейчас же. Если потеряешь — просто создашь новый.

---

## Куда его вставить

Как и с YouTube — никуда вручную. Когда провижнер спросит при установке (или позже, если решишь добавить) — пришли ключ **сообщением в чат боту**. Он запишет сам.

Ключ секретный, как пароль. Никому, кроме бота по запросу.

---

## Альтернативы

- **Уже есть Deepgram** (например, пользуешься транскрибатором) — можешь дать ключ Deepgram вместо OpenAI, расшифровка пойдёт через него.
- **OpenRouter** — если пользуешься им, можно чистить транскрипты через него.

Про эти варианты скажи в поддержке — подскажем, какой ключ куда.
