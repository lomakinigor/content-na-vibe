# Как получить ключ Deepgram (для транскрибации своих видео)

Этот ключ нужен, если хочешь загружать **своё видео или эфир** и получать из него готовый текст — а из текста агент соберёт сценарий. Без него работает всё остальное (тренды, сценарий по теме, презентация, лид-магнит) — Deepgram нужен только для расшифровки твоих записей.

При регистрации Deepgram даёт бесплатные кредиты (хватает на десятки часов записей). Времени — 5 минут, делается один раз.

**Имя переменной (важно):** `DEEPGRAM_API_KEY` — добавляешь её именно под этим именем (см. «Куда вставить»).

---

## По шагам

**1. Зарегистрируйся**
Перейди на [console.deepgram.com/signup](https://console.deepgram.com/signup) и создай аккаунт — проще всего через Google или GitHub (одна кнопка), либо по почте.

**2. Открой раздел ключей**
После входа в левом меню выбери **API Keys** (ключи API). Прямая ссылка: [console.deepgram.com](https://console.deepgram.com/).

**3. Создай ключ**
Нажми **Create a New API Key** → дай имя (например, «content-na-vibe») → права оставь по умолчанию (**Member**) → **Create Key**.

**4. Скопируй ключ сразу**
Ключ покажут **один раз** — длинная строка букв и цифр. Скопируй её сейчас; если закроешь окно и не сохранил — просто создашь новый.

---

## Куда его вставить

Два способа:
1. **При установке пакета** — провижнер (@AgiFactory_bot) сам попросит ключ, если он нужен, — просто пришли его сообщением в чат.
2. **В любой момент сам** — в своём боте: **`/settings → 🔑 → ✏️ Добавить свою`**, имя переменной `DEEPGRAM_API_KEY`, значение — сам ключ.

Ключ — как пароль. Не выкладывай его нигде и не отправляй никому, кроме бота по его запросу.

---

## Частые вопросы

**Это точно бесплатно?**
На старте Deepgram даёт бесплатные кредиты — их хватает на десятки часов расшифровки. Когда закончатся, можно привязать карту и платить по факту (это уже твоё решение, агент карту не привязывает).

**Обязательно ли это?**
Нет. Deepgram нужен только для сценария «по своему видео». Если ты диктуешь тему или берёшь идею из трендов — ключ не нужен.

**А если у меня уже есть ключ Deepgram?**
Используй его — второй создавать не надо. Просто добавь под именем `DEEPGRAM_API_KEY`.

**Какие форматы видео можно?**
mp4, mov, mkv, avi, webm — агент сам вытащит из них звук (нужен ffmpeg, он ставится с пакетом) и отправит на расшифровку.
