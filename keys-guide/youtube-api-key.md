# Как получить ключ YouTube (обязательный, бесплатно)

Этот ключ нужен, чтобы агент искал залетающие ролики по твоей теме. Он бесплатный, лимитов хватает с запасом. Времени — 10-15 минут, делается один раз.

Тебе понадобится любой аккаунт Google (тот же, что и для почты Gmail).

**Имя переменной (важно):** `YOUTUBE_API_KEY` — добавляешь её именно под этим именем (см. «Куда вставить» ниже).

---

## По шагам

**1. Открой Google Cloud Console**
Перейди на [console.cloud.google.com](https://console.cloud.google.com/) и войди своим Google-аккаунтом.

**2. Создай проект**
Вверху слева выпадающий список проектов → **«Создать проект»** → любое имя (например, «youtube-trends») → **Создать**. Подожди 10-20 секунд и выбери его вверху.

**3. Включи YouTube Data API v3**
Прямая ссылка (проверь, что вверху выбран нужный проект): [console.cloud.google.com/apis/library/youtube.googleapis.com](https://console.cloud.google.com/apis/library/youtube.googleapis.com) → нажми **«Включить» / Enable**.

**4. Создай ключ**
Открой [console.cloud.google.com/apis/credentials](https://console.cloud.google.com/apis/credentials) → вверху **«+ Создать учётные данные»** → **«Ключ API»**. Появится строка вида `AIzaSy...` — это он.

**5. Скопируй ключ**
Нажми на иконку копирования рядом с ключом. Это и есть твой ключ.

**6. (Рекомендуется) Ограничь ключ — для безопасности**
В том же окошке нажми **Restrict Key / «Ограничить ключ»** → в разделе **API restrictions** выбери **Restrict key** → в списке отметь только **YouTube Data API v3** → **Save**.
Так, даже если ключ куда-то утечёт, им нельзя будет пользоваться для другого.

---

## Куда его вставить

Два способа:
1. **При установке пакета** — провижнер (@AgiFactory_bot) сам попросит ключ, просто пришли его сообщением в чат.
2. **В любой момент сам** — в своём боте: **`/settings → 🔑 → ✏️ Добавить свою`**, имя переменной `YOUTUBE_API_KEY`, значение — сам ключ.

Ключ — как пароль. Не выкладывай его нигде и не отправляй никому, кроме бота по его запросу.

---

## Частые вопросы

**Это точно бесплатно?**
Да. У YouTube API есть бесплатная суточная квота (10 000 единиц) — для поиска трендов этого хватает с большим запасом. Карту привязывать не нужно.

**Ключ не появляется / кнопка серая**
Убедись, что на шаге 3 именно **включил** YouTube Data API v3 (кнопка стала «Manage / Управлять»). Без включённого API ключ не даст искать.

**Можно ли один ключ на несколько проектов?**
Да, один ключ работает. Но если упрёшься в лимит — создашь второй проект и второй ключ.

**Просят настроить «экран согласия OAuth»**
Игнорируй — для API-ключа это не нужно, он работает без него. Платёжную карту привязывать тоже не требуется.
