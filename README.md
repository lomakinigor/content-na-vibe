# Контент на вайбе

Чистый пакет агента-продюсера для Usjarvis. Он помогает пройти путь от идеи ролика до сценария, лид-магнита, презентации и суфлёра.

## Что входит

- `producer-orchestrator` - ведёт весь процесс;
- `trend-hunter` - ищет тренды на YouTube;
- `scenario-writer` - пишет сценарий;
- `video-transcriber` - расшифровывает видео;
- `presentation-maker` и `lead-magnet-maker` - создают готовые материалы.

## Установка

Этот пакет подключается скриптом из репозитория `lomakinigor/jarvis-architect`. Он создаёт виртуальное окружение и устанавливает зависимости из `requirements.txt`.

Файл `voice/author-voice.md` создаётся на конкретном сервере после знакомства агента с владельцем. В GitHub он не хранится.
