# Обновление пакета

Исходная рабочая копия была восстановлена из установленного пакета Agent Factory на `my-vps`. В ней не сохранился Git remote, а публичный GitHub-репозиторий пакета не найден.

Поэтому автоматическая синхронизация с донором пока невозможна. Перед обновлением нужно получить новую официальную поставку пакета, проверить её на личные данные и только потом перенести изменения сюда отдельным коммитом.
