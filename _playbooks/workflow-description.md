# Режим создания YouTube Description (SEO-описание)

## Триггеры — когда активировать

«описание», «description», «напиши описание», «сделай описание к видео», «SEO описание», «метаданные», «заголовок для YouTube», «title», «теги», «подготовь к публикации», «загружаю на YouTube»

## Как работать

1. **Прочитать** промпт: `youtube-scenario-kit/prompts/description.txt`
2. **Прочитать** гайд: `youtube-scenario-kit/knowledge/youtube-seo-description-guide.md`
   Это ГЛАВНЫЙ источник истины по SEO-оптимизации. Все решения — только по нему.
3. **Собрать входные данные** (в порядке приоритета):
   - `scripts/{slug}/promises-analysis.md` (если есть — главный источник)
   - `scripts/{slug}/ready-for-filming/{slug}.md`
   - `scripts/{slug}/transcript.txt`
   - Информация от пользователя
4. **Создать** по структуре из промпта: заголовок (3 варианта) + описание (5 зон) + теги
5. **ОБЯЗАТЕЛЬНО** запустить самопроверку из раздела "Самопроверка агента" в гайде
6. Выдать итоговое заключение: все ✅ или что нужно доделать
7. Сохранить результат в `scripts/{slug}/postproduction/content/youtube-description.md`

## Структура описания (5 зон)

| Зона | Что | Размер |
|---|---|---|
| 1 — Above the fold | Ключ + результат для зрителя | 150-160 символов |
| 2 — Контент | Семантический контекст, LSI-ключи | 200-250 слов |
| 3 — Таймкоды | С 00:00, названия = ключевые слова | По числу блоков |
| 4 — Ссылки | Воронка → смежные видео → Telegram | — |
| 5 — Хэштеги | Ровно 3-5 штук в самом конце | 3-5 |

## Правила заголовка

- Ключ — в первые 3-5 слов
- Длина: 50-60 символов (мобайл-тест)
- Минимум 1 триггер: curiosity / страх / желание
- Предложи 3 варианта, порекомендуй лучший

## Самопроверка (23 пункта) — ОБЯЗАТЕЛЬНА

После создания описания агент ВСЕГДА запускает чеклист из гайда и выдаёт таблицу + итоговое заключение. Без самопроверки задача не считается выполненной.

Пункт 23 — факт-чек: фактические утверждения (цифры, названия, обещания) соответствуют видео или помечены `[УТОЧНИТЬ]`. Канонический чек-лист — в гайде: `youtube-scenario-kit/knowledge/youtube-seo-description-guide.md` → «Самопроверка агента».
