# Формулы и структуры Reels — универсальное ядро

> **Это нишенезависимый источник.** Формулы и структуры работают на ЛЮБОЙ теме —
> вайбкодинг, нейросети, заработок, автоматизация, личный опыт. Тема подставляется
> и адаптируется в момент генерации (режим F), а не зашивается в шаблоны.
>
> Первоисточник: `Помощник/Reels & Carusel/ШАБЛОНЫ_РИЛСОВ.md` (перенесён и обобщён).
> Для длинных YouTube-роликов действует другой источник — `research/austin-marchese-razbor.md`.
> Reels ≠ длинный ролик: здесь короче, проще, удар в первые 3 секунды.

---

## Главное правило

**Хук — это 80% успеха.** Если зритель не остановился за 1 секунду — Reel мёртв.
Дальше по важности: **один месседж на ролик**, **простой язык**, **CTA в конце**.

---

## Формулы хуков (первые 1–3 секунды)

18 проверенных формул по 6 категориям. Примеры разноплановые нарочно — чтобы
формула читалась как формула, а не как тема. При генерации подставляется реальная тема.

### Категория 1 — Кейс / Результат
```
1. «[Кто] сделал [результат] — и получил [цифра]»
   → «Медсестра собрала бота — и заработала первые 25 000 ₽»

2. «Он/она никогда не [навык]. А потом [результат]»
   → «Она никогда не писала код. А потом собрала приложение за вечер»

3. «[Кто] тратил [время] на [задачу]. Теперь — [короткое время]»
   → «Владелец кафе делал меню 3 часа. Теперь — 15 минут»
```

### Категория 2 — Деньги / Заработок
```
4. «Как получить [сумма] с помощью [инструмент/подход]»
   → «Как заработать первые 30 000 ₽ на нейросетях»

5. «[Сумма] — столько стоит [услуга]. А ты можешь делать это сам»
   → «80 000 ₽ — столько берёт маркетолог. А нейросеть делает это бесплатно»

6. «Покажу [число] способов [результат]. Без [сложное условие]»
   → «Покажу 5 способов заработать на ИИ. Без кода»
```

### Категория 3 — Лайфхак / Экономия
```
7. «Этот [приём] экономит [число] часов в неделю»

8. «[Задача] за [короткое время]. Показываю»
   → «Контент-план на месяц за 10 минут. Показываю»

9. «Одна [штука] — и [результат]»
   → «Одна команда — и лимитов хватает втрое дольше»
```

### Категория 4 — Ловушка мышления
```
10. «Все думают что [миф]. На самом деле [правда]»
    → «Все думают, что это дорого. Считаем вместе»

11. «Я тоже так думал. А потом [что изменилось]»
    → «Я тоже думал, что это только для программистов. А потом...»

12. «[Фраза, которую говорят] — и это стоит тебе [цена ошибки]»
    → «"Потом разберусь" — и это стоит тебе денег»
```

### Категория 5 — Автоматизация / Демо
```
13. «У меня [число] помощников. Ни одной зарплаты»

14. «Эта штука [действие] — без моего участия»
    → «Этот бот отвечает клиентам 24/7 — без меня»

15. «Раньше [старый способ]. Теперь [новый способ]»
    → «Раньше я писал рассылку 2 часа. Теперь — за 5 минут»
```

### Категория 6 — Личная история
```
16. «[Ситуация из жизни]. И я понял одну вещь...»
    → «Сижу ночью, второй час тестирую. И понял одну вещь...»

17. «Короче, [что сделал] — и это [эмоция]»
    → «Короче, подключил бота к делу — и это просто огонь»

18. «Ребят, я понял одну штуку про [тема]»
```

**Визуальные хуки (первая секунда, для монтажёра):**
- Показать РЕЗУЛЬТАТ сразу (готовый экран, скриншот)
- Текст на экране крупно: 3–5 слов
- Сплит «Было → Стало»
- Быстрый zoom на результат

## 5 структур Reels (посекундно)

Порядок и хронометраж адаптируются под тему. По умолчанию — 20–35 секунд.

### Структура 1 — Кейс-результат (приоритет)
**Для:** кейсы, трансформации • **15–30 сек**
```
[0-3]   ХУК — результат («Медсестра заработала 25К»)
[3-10]  КТО — «Марина, 38, медсестра. Не технарь вообще»
[10-20] ЧТО СДЕЛАЛА — «За 2 недели научилась. Первый клиент — клиника»
[20-25] РЕЗУЛЬТАТ — цифры, скриншот
[25-30] CTA — «Хочешь так же? Подписывайся»
```

### Структура 2 — Демо / лайфхак (высокий приоритет)
**Для:** приёмы, промпты, автоматизация • **20–25 сек**
```
[0-3]   ХУК на камеру — «Контент-план за 10 минут. Показываю»
[3-5]   Переход на экран
[5-18]  ПОКАЗ — вводим → видим результат (рутину ускорить 2-4x)
[18-22] РЕЗУЛЬТАТ — пауза на готовом
[22-25] CTA на камеру — «Сохрани. Подписывайся»
```
**Ключевое:** показывать РЕЗУЛЬТАТ, а не процесс.

### Структура 3 — Ловушка мышления (ложное завершение)
**Для:** мифы, стереотипы • **20–30 сек**
```
[0-3]   ХУК — «Это дорого»
[3-12]  РАЗВИТИЕ — «Мне пишут каждый день: дорого. Окей, считаем»
[12-20] ФАКТЫ — конкретные цифры сравнения
[20-23] ЛОЖНЫЙ КОНЕЦ — «Но да, это дорого...»
[23-28] ПОВОРОТ — «...дорого НЕ использовать»
[28-30] CTA — «Подписывайся — разрушаю ловушки каждую неделю»
```

### Структура 4 — Пошагово / «вот 3 шага»
**Для:** инструкции, монетизация • **25–35 сек**
```
[0-3]   ХУК — «Как получить [результат]» ИЛИ «Три штуки, и [результат]»
[3-8]   КОНТЕКСТ — «Даже если ты никогда не...»
[8-25]  ШАГИ — 3 шага, по 5 сек, конкретно
[25-30] РЕЗУЛЬТАТ — «Через 2-3 недели начинают получать...»
[30-35] CTA — «Подписывайся — завтра шаг 1 подробно»
```

### Структура 5 — Личная история + мост к теме
**Для:** вовлечение, философский регистр • **30–45 сек**
**Не чаще 1 раза в 2 недели. Только для настоящих историй.**
```
[0-5]   ЗАЦЕПКА — личная ситуация
[5-20]  ИСТОРИЯ — детали, эмоция
[20-30] МОСТ — «И вот это ощущение — оно не только про...»
[30-40] ПРИВЯЗКА к теме
[40-45] CTA — эмоциональный
```

## Правило простого языка (КРИТИЧНО)

**Пиши так, как говоришь другу. Как читается — так и произносится.**

- Короткие фразы. Одна мысль — одно предложение.
- Никаких книжных и абстрактных оборотов. Если слово не скажешь вслух за столом — не пиши.
- Термин — сразу разжевать бытовым словом или примером.
- Числа — конкретные («втрое», «за 5 минут», «25 000 ₽»), не «значительно» и «в разы».
- От первого лица, живая интонация, слова-маркеры: «короче», «смотри», «вот в чём фишка», «прям», «ребят».

**Хук — либо сразу в боль, либо сразу в решение.**
Не подводить издалека. Первые 3 секунды: боль зрителя ИЛИ «вот три шага» / «вот как это работает».

### Стоп-лист (не употреблять в тексте озвучки)
`холостой ход` · `премиум` · `оптимизировать` · `надстройка` · `костыль` · `микро-тюнинг`
· `функционал` · `юзкейс` · `на самом деле является` · `в рамках` · `осуществлять`
· `данный` · `является` · любые длинные сложноподчинённые в первой фразе (>15 слов)
· термин без немедленного разжёвывания.

Замена по смыслу: «холостой ход» → «впустую / на ерунду»; «оптимизировать» → «настроить /
ускорить»; «премиум» → «дорогой тариф»; «функционал» → «возможности / что он умеет».

## Сигналы виральности Instagram (по приоритету)

1. **Отправки в DM** — сигнал №1. Контент, который хочется скинуть другу (кейсы, wow-демо).
2. **Сохранения** — №2. Промпты, гайды, чек-листы, пошаговые инструкции.
3. **Watch time** — % досмотра (цель 75%+, поэтому Reel КОРОТКИЙ + поворот в конце).
4. **Комментарии** — вовлечённость (кодовое слово в комментах работает и на воронку).
5. **Лайки** — наименее важный.

**Вывод для сценария:** делай так, чтобы захотелось либо **отправить**, либо **сохранить**.
Короткий ролик + поворот в конце = высокий досмотр.

## Правила монтажа (кратко, для ТЗ монтажёру)

- Субтитры ОБЯЗАТЕЛЬНО (до 70% смотрят без звука), по 2–4 слова, крупно, контрастно.
- Смена плана каждые 2–3 секунды.
- Говорящая голова: крупный план (лицо 40–60% экрана), хороший свет, zoom на ключевых точках.
- Скринкаст: zoom на зону фокуса, стрелки/выделения, рутину ускорять 2–4x.
