# Воркфлоу: 📱 Reels

Третий формат канала наряду с длинными YouTube-роликами и Shorts. Два пути:
1. **От донора** — смотрим чужие Reels (Instagram, TikTok, YouTube Shorts) →
   транскрибируем → пишем свои сценарии под вертикальную съёмку.
2. **Из темы (режим F)** — задаём тему → генерим хук + текст + CTA с нуля,
   без чужого ролика. См. раздел «Режим F».

> 💡 **Разбор ОДНОГО донора — скилл `/video <url>`** (`~/.claude/skills/video/`): скачивает,
> транскрибирует и (по запросу) смотрит кадры → `visual.md`, выдаёт разбор и отдаёт эстафету
> в режимы C/D. Для вертикалей «глаза» обычно не нужны (говорящая голова) — включай флагом.
> ⛔ НЕ перехватывает Fast production: 2+ ссылок без slug — это по-прежнему авто-режим D.

**Источники стиля для ЛЮБОГО Reel (в порядке приоритета):**
1. **`voice/author-voice.md`** — ГОЛОС №1. Реальная речь автора
   из его записанных Reels: скелет, обороты («Короче», «Смотри что внутри», «Вот в чём
   фишка»), метафоры-уколы, провокационный хук, правило CTA. Эталоны — рядом в `эталоны.md`.
2. **`knowledge/reels-hook-formulas.md`** — структуры, стоп-лист, сигналы виральности
   (нишенезависимо).

`austin-marchese-razbor.md` — только для длинных YouTube-роликов, для Reels он даёт
книжный регистр (проверено).

## Архитектура хранения

| Что | Где | Под git? |
|---|---|---|
| Видео чужих Reels | `~/Movies/Reels/{slug}/source.<ext>` | ❌ нет |
| Транскрипции, заметки, meta | `reels/sources/{slug}/` | ✅ да |
| Свои сценарии под съёмку | `reels/scripts/{slug}/` | ✅ да |
| **Fast production** (рерайты) | `reels/production/YYYY-MM-DD.md` | ✅ да |

**Слаг — ОДИН** для пары source ↔ script когда сценарий буквально по одному
референсу. Если своё видео делается на основе нескольких Reels — у скрипта
свой slug, в `inspired-by.md` перечисляются использованные `sources/*`.

## Маршрутизация (продолжение `file-routing.md`)

| Тип | Куда |
|---|---|
| Чужой Reel (yt-dlp + Deepgram) | `reels/sources/{slug}/transcript.txt` + `meta.md` |
| Свой Reel (сценарий под съёмку) | `reels/scripts/{slug}/script.md` |
| Своя запись Reel после съёмки | пока используем `reels/scripts/{slug}/transcript.txt` (как в `scripts/{slug}/`) |
| **Fast production** (режим D) | `reels/production/YYYY-MM-DD.md` — один файл на дату |

**Не путать:**
- `transkrib/` — чужие YouTube-видео, плоская структура, research
- `reels/sources/` — чужие Reels, по slug-папкам, research
- `scripts/{slug}/` — свои YouTube-съёмки, полный постпродакшн
- `reels/scripts/{slug}/` — свои Reels-сценарии

## Cookies для Instagram

Reels (`/reel/...`) и карусели (`/p/...` с несколькими слайдами) требуют логин. Один раз экспортировать через расширение Chrome **«Get cookies.txt LOCALLY»**, формат **Netscape**, сохранить в `.instagram-cookies.txt` в корне проекта (вне git, в `.gitignore`). Все три скрипта (`reel.sh`, `reel-transcript.sh`, `carousel.sh`) автоматически подхватывают этот файл.

Куки протухают раз в несколько недель — перезалить тем же способом.

## Как Claude работает в режиме «📱 Reels»

### Триггеры

- Ссылка на `instagram.com/reel/...`, `tiktok.com/...`, `youtube.com/shorts/...`
- Слова: «reel», «релс», «релсы», «вертикалка», «короткий ролик»
- Явная команда: «режим Reels» / «постмотрим релсы»

### Под-режимы

**A. Загрузка нового референса** (есть URL):

1. Спросить slug (kebab-case, кратко по теме: `ai-coach-hook`, `claude-code-fast`)
2. Запустить `./tools/reel.sh <URL> <slug>`
3. Когда видео откроется в QuickTime — попросить заполнить `meta.md` (раздел Заметки) или предложить разобрать вместе по транскрипции

**B. Разбор уже скачанного** (есть slug в `reels/sources/`):

1. Прочитать `meta.md` и `transcript.txt`
2. Разобрать структуру: хук → развитие → CTA
3. Записать выводы в раздел «Заметки» в `meta.md`

**C. Свой сценарий по референсам**:

1. Спросить целевой slug для скрипта
2. Спросить какие `sources/*` вдохновили (одно или несколько)
3. Создать `reels/scripts/{slug}/inspired-by.md` со списком sources
4. Написать `script.md` — голос автора, формат вертикалки 30-90 секунд

**D. Fast production** (массовая подготовка к съёмке):

Когда есть несколько ссылок на референсы и нужно быстро получить готовые тексты для суфлёра.

**Авто-триггер:** 2+ ссылок на Reels в одном сообщении без указания slug → сразу в работу, бриф не нужен.

**Альтернатива:** команда `/reels <URL> <URL>...`.

**Пайплайн:**

1. Для каждой ссылки запустить:
   ```bash
   # Reel/TikTok/Shorts (видео + аудио)
   ./tools/reel-transcript.sh <URL>

   # Карусель Instagram /p/... (слайды с текстом)
   ./tools/carousel.sh <URL>      # → /tmp/carousel-<shortcode>/*.jpg
   # Затем читаю каждый слайд через Read tool, извлекаю текст вручную
   ```
   - `reel-transcript.sh` качает только аудио (yt-dlp `-x --audio-format mp3`), транскрибирует через Deepgram (`transcribe.py`), удаляет временные файлы, выводит транскрипт в stdout
   - `carousel.sh` качает все слайды через gallery-dl (Instagram cookies нужны)

2. Для каждого транскрипта:
   - Выделить хук (первые ~20 слов) — **НЕ МЕНЯТЬ**, копировать дословно
   - Тело — **по умолчанию ТОЧНЫЙ ПЕРЕВОД/ПЕРЕСКАЗ** (см. ниже «Два режима перевода»)
   - Если из одной ссылки нужно 2+ ролика: оригинальный хук идёт ПЕРВОМУ, остальным придумываем новый и помечаем `**[ХУК — НОВЫЙ]**`

**Два режима перевода (КРИТИЧНО — частая боль):**

| | D-точный (ДЕФОЛТ) | D-рерайт (по явной просьбе) |
|---|---|---|
| Что делаю | Верно перевожу/пересказываю смысл оригинала | Глубоко переписываю под голос автора |
| Можно ли добавлять | **НЕТ.** Не добавляю смыслов, фактов, фраз, которых не было в оригинале | Да, адаптирую примеры и интонацию |
| Вставки автора | Только когда он явно сказал что добавить → помечаю `[+ Дима]` | Вплетаю по стилю |
| Когда | Всегда по умолчанию, особенно для англоязычных роликов | Только если автор прямо просит «перепиши / рерайт» |

**Правило D-точного (запомнить):** перевод ≠ сочинение. Задача — сказать ТО ЖЕ САМОЕ
по-русски простым языком (`reels-hook-formulas.md` → «Правило простого языка»).
Если хочется что-то добавить от себя — не добавляю молча, а спрашиваю автора.
Источник правила: `Парсер Новостей из ТГ/prompts/reels.txt` — «Добавлять информацию,
которой не было в посте — ЗАПРЕЩЕНО».

3. Собрать всё в `reels/production/YYYY-MM-DD.md` (один файл на дату, накапливается в течение дня — дописываем в конец).

4. Формат блока:

```markdown
---

## Reel N

### Референс
<URL>

### Оригинал
<транскрипт как есть>

### Обещание автора (для воронки)
<что автор обещает в конце видео — лид-магнит, гайд, бонус. Если обещания нет — так и пишем>

**Что подготовить под мою воронку:** <конкретный документ/бонус, кодовое слово, куда ведёт воронка>

### Мой текст для записи
**[ХУК — НЕ ИЗМЕНЁН]** <первые ~20 слов точно как в оригинале>

<глубокий рерайт остального>

### Заметки к записи
[placeholder]

### CTA
**Instagram:** [placeholder]
**YouTube:** [placeholder]
**ВК:** [placeholder]

### Готовое видео (для монтажа)
[Google Drive: вставить ссылку после съёмки]
```

**Зачем поле «Обещание автора»:** автор референса в конце часто обещает лид-магнит («Напиши „плагин“ — пришлю список»). Это сигнал какой документ подготовить под СВОЮ воронку до съёмки — чтобы когда Reel выйдет, бонус уже был готов. Если обещания нет — пиши «прямого обещания нет» и предложи идею для усиления.

**Зачем поле «Готовое видео» в конце:** автор записывает Reel → загружает на Google Drive → вставляет ссылку → отправляет весь файл монтажёру. Поле в конце блока, потому что заполняется ПОСЛЕДНИМ — после всей подготовки и съёмки. Монтажёр получает в одном документе: референс, текст, заметки, CTA и **исходник записи**.

5. Файл накапливается в течение дня — дописываем в конец

**Когда использовать D vs A+C:**
- **D (Fast production)** — массовая съёмка, 5-10 референсов за раз, нужен быстрый результат
- **A+C** — глубокий разбор одного референса, сохранение видео, детальные заметки

**E. Slice mode** (нарезка из своих YouTube-роликов):

Когда есть длинный YouTube-ролик с несколькими идеями — нарезаем его на 3-7 коротких Reels. Источник — твой материал, не чужой.

**Триггер:** автор говорит «нарежь из ролика X несколько Reels» / «сделай Reels из транскрипции». Slug ролика или путь к `transcript.txt` в `scripts/{slug}/`.

> ⚠️ **✅-конвенция путей.** Slice mode работает с уже ЗАПИСАННЫМИ роликами, а их папки на диске называются `scripts/✅ {slug}/` (префикс «✅ » + пробел). Везде ниже `scripts/{slug}/` — это плейсхолдер; реальный путь к транскрипту записанного ролика: `scripts/✅ {slug}/transcript.txt`. Перед чтением проверь `ls scripts/`, как папка называется на самом деле.

**Отличия от D:**

| | Режим D (рерайт) | Режим E (нарезка) |
|---|---|---|
| Источник | URL чужого Reel'а | `scripts/{slug}/transcript.txt` (свой YouTube) |
| Хук | оригинальный, не менять | **новый** — пересобираем под формат вертикали |
| Тело | глубокий рерайт | **выжимка** ключевой идеи + конкретика |
| Обещание | анализ концовки чужого | **твоё** под СВОЮ воронку |
| Референс | URL | `scripts/{slug}/transcript.txt` + примерный тайминг |

**Пайплайн:**

1. Прочитать транскрипцию целиком (`Read scripts/{slug}/transcript.txt`)
2. Выделить «единицы контента» (1 принцип / 1 фишка / 1 история = 1 Reel)
3. Согласовать список Reel'ов с автором (через AskUserQuestion если нужно)
4. **Спросить YouTube-ссылку** на ролик (если ролик уже опубликован) — чтобы вставить deep-link с таймингом в каждый Reel
5. Для каждого Reel:
   - Хук = «крючок» из идеи (числа, контринтуитив, цитата). Помечать `**[ХУК — НОВЫЙ]**`
   - Тело = выжимка 4-6 коротких абзацев под суфлёр, с конкретикой и метафорами
   - Обещание = твой лид-магнит (часто общий конспект на весь YouTube-ролик)
   - Референс = YouTube-ссылка с таймингом в секундах (`youtu.be/ID?t=NNN`) + путь к `transcript.txt`
6. Дописать в `reels/production/YYYY-MM-DD.md`. Раздел можно оформить отдельно: `# Часть 2 — Slice mode (нарезка из своих YouTube)`

**Формат блока «Референс» в Slice mode:**

```markdown
### Референс
**YouTube:** [«НАЗВАНИЕ РОЛИКА» — с MM:SS](https://youtu.be/VIDEO_ID?t=SECONDS)
**Транскрипция:** `scripts/{slug}/transcript.txt` (тайминг ~MM:SS-MM:SS)
```

YouTube-параметр `?t=NNN` — секунды от начала. Конвертация: `MM:SS` = `MM*60 + SS`.
Например 14:42 → 14*60+42 = 882 → `?t=882`.

**Принципы Slice mode:**
- **Факт-чек:** цифры, названия, свойства инструментов — только из транскрипта или проверенного источника, спорное помечай `[УТОЧНИТЬ]`. Правило — `knowledge/workflow-scenario.md` → «Факт-чек»
- 1 идея = 1 Reel — не пихай 3 принципа в один ролик
- Каждый Reel начинается с яркого «крючка»: число, контринтуитивное утверждение, цитата
- Тело 30-60 секунд (4-6 коротких абзацев)
- Концовка — твоё CTA с лид-магнитом
- Можно использовать общий лид-магнит для серии (один конспект → одно кодовое слово на 5-7 Reel'ов)

**F. Reel из темы** (сценарий с нуля, без донора):

Когда есть только тема — не чужой ролик и не транскрипт своего YouTube. Аналог
💡-режима для длинных роликов, но для вертикали. На выходе: 3 варианта хука + текст
+ CTA. Тема **любая** (вайбкодинг, нейросети, заработок, автоматизация, личный опыт).

**Триггер:** `/reel-from-theme <тема>` или «Reel из темы», «сделай вертикалку про X»
без ссылки на референс.

**Пайплайн:**

1. **Собрать микро-бриф** (если не задан в теме): для кого + какой результат зрителю.
   Если тема ясна — не переспрашивать, идти дальше.
2. **Прочитать источники стиля** (в порядке): `voice/author-voice.md`
   (голос №1) → `knowledge/reels-hook-formulas.md` (структуры, стоп-лист).
3. **Выбрать ОДИН крючок** (1 идея = 1 Reel): боль / число-контраст / цитата /
   ловушка мышления / «вот 3 шага».
4. **Сгенерировать 3 хука** по РАЗНЫМ формулам (обычно: удар в боль + сразу решение
   + ловушка/контраст). автор выбирает или миксует.
5. **Собрать тело** по подходящей структуре (чаще структура 2 «демо» или 4 «шаги»),
   20–40 секунд, простым разговорным языком. Прогнать через стоп-лист.
6. **CTA** — только placeholder × 3 платформы (Instagram / YouTube / ВК). Никогда не
   генерить — у автора свои воронки. Плюс идея лид-магнита под воронку.
7. **Дописать в `reels/production/YYYY-MM-DD.md`** тем же форматом, что D/E, но
   вместо блока «Референс» — блок «Тема», блок «Оригинал» отсутствует.

**Движок-промпт:** `youtube-scenario-kit/prompts/reel_topic.txt`.

**Принципы (те же, что для всех Reels):**
- Хук либо сразу в боль, либо сразу «вот 3 шага» — не подводить издалека
- 1 идея = 1 Reel • простой язык, как говоришь другу • конкретные числа
- **Факт-чек:** контент с нуля — факты и цифры только из проверенного источника (сессия, доки, скрин), спорное помечай `[УТОЧНИТЬ]`. Правило — `knowledge/workflow-scenario.md` → «Факт-чек»
- Ниша к формулам НЕ пришивается — структура универсальна, тема наполняет её

**Формат блока «Тема» в режиме F:**

```markdown
### Тема
<тема одной фразой> • для кого: <ЦА> • результат: <что зритель получит>

### Хуки (выбрать один)
1. **[боль]** <хук>
2. **[решение / 3 шага]** <хук>
3. **[ловушка / контраст]** <хук>

### Мой текст для записи
<выбранный хук + тело простым языком, 20–40 сек>

### CTA
**Instagram:** [placeholder]
**YouTube:** [placeholder]
**ВК:** [placeholder]

### Лид-магнит под воронку (идея)
<что подготовить + кодовое слово>

### Готовое видео (для монтажа)
[Google Drive: вставить ссылку после съёмки]
```

## Бриф для режима 📱 Reels

Перед работой собирай:

1. **Под-режим:** A / B / C / D / E / F
2. Для A: URL + slug
3. Для B: какой slug разбираем
4. Для C: целевой slug + список sources + главный месседж
5. Для D: просто ссылки (без slug, без брифа — сразу в работу)
6. Для E: slug ролика в `scripts/` + сколько Reel'ов нужно + общий лид-магнит (если есть)
7. Для F: тема (одной фразы достаточно). Опционально — для кого + желаемый результат

## Принципы для своих Reels

- **Хук в первые 3 секунды** или зритель свайпнул
- **Один месседж** на ролик — Reels не выдерживают двух идей
- **30-60 секунд** оптимум, до 90 если плотно
- **Текст на экране** дублирует ключевые точки (смотрят без звука)
- **CTA в конце:** подписка, ссылка в био, переход в Telegram

Голос автора и стиль контента — те же что для YouTube
(`SOUL.md`, `youtube-scenario-kit/knowledge/writing-style.md`).

## Формула хука и стиль текста (КРИТИЧНО)

**Перед написанием любого хука И тела ролика — прочитать в таком порядке:**
1. **`voice/author-voice.md`** — ГОЛОС №1 (реальная речь автора). Затем `knowledge/reels-hook-formulas.md` — 18 формул хуков, 5 структур, стоп-лист, сигналы виральности
2. `voice/author-voice.md` — стиль автора
3. `voice/author-voice.md` — как писать «как автор»
4. `~/.claude/skills/content-writer/references/hooks-and-engagement.md` — шаблоны хуков
5. `research/austin-marchese-razbor.md` — доп источник, но ТОЛЬКО для длинных YouTube (для Reels даёт книжный регистр)

**Шаблоны открывающих фраз (по убыванию силы):**
1. «У кого было такое — [ситуация боли]?» — фирменный паттерн автора из его роликов
2. «Знакомо чувство, когда [ситуация]?» — вариация
3. «Я раньше думал [X]. А потом дошло — [Y]» — антитеза «было/стало»
4. «Я такой: стоп / прифигел» — эмоциональная реакция на цитату
5. «[Цитата эксперта]. От этой фразы у меня мурашки»

**Структура блока (формула Austin Marchese, ratio ×9.3):**
1. Хук: боль или цитата + эмоция
2. «Я такой:» — реакция
3. Антитеза «большинство делает X / правильно Y»
4. Кейс с провалом (релевантность)
5. Конкретный инструмент / клавиша / промпт
6. Pro tip

**Главные правила стиля (проверены правками автора 2026-05-01):**
- **Одна бытовая метафора на ролик, обязательно.** Эталоны: «карбюратор vs современная машина» (Bitter Lesson), «ремонт квартиры — сначала план потом стены» (Plan Mode), «прораб задаёт 50 вопросов» (Discovery), «холодильник к концу недели» (контекст), «Ctrl+Z в Ворде» (Rewind), «должностная инструкция помощнику» (CLAUDE.md), «купи хлеба + пришли фото» (проверь)
- **Запрещены абстракции:** «общая модель vs специфичная», «эссе X», «костыль / микро-тюнинг / надстройка». Если идея сложная — пример из быта, опираясь на контекст оригинала или подтверждения в интернете
- **Слова-маркеры:** «Короче», «Ребят», «прям», «нафиг», «париться», «Вот в чём фишка», «вот смотрите», «угадай где меньше боли», «у меня клиент»
- **От первого лица + личная история** в начале текста
- **Конкретные числа в каждом тексте**

**Анатомия сильного хука (3 секунды = 8-15 слов):**

1. **Pattern interrupt** — шок-фраза / неожиданное число / цитата с авторитетом / провокация
2. **Личная боль** — фирменный паттерн «у меня было что...», «Полчаса я...»
3. **Контраст «было/стало»** — конкретные числа (час → 1 минута)
4. **Open loop** — «и сейчас покажу», «один способ лечит это», «прочитай эту фразу ещё раз»
5. **Конкретный артефакт** — не «эта штука», а название (Shift+Tab, /compact)

**Запрещённые шаблоны:**
- «Большинство об этом не знают» — избито (можно изредка, но не в каждом хуке)
- Длинные сложноподчинённые предложения в первой фразе
- Дублирование угла между Reel'ами (если 2 ролика про одно — у каждого свой угол)

**Рабочие примеры (по итогу 2026-05-01):**
- Контраст: «Час работы. Каждую неделю. Полгода подряд. А потом — 1 минута»
- Боль+интрига: «Claude сломал мой проект за 3 минуты. Я восстановил его за 2 секунды»
- Цитата+pattern interrupt: «"ИИ никогда не будет так плох как сегодня". Прочитай ещё раз»
- Pattern interrupt: «Claude согласится с любой твоей идеей. Даже самой тупой»

## Съёмочная страница HTML (`*-shooting.html`)

**Зачем:** `.md` неудобно читать с телефона-суфлёра во время съёмки — много служебных полей (Обещание автора, Что подготовить под мою воронку и т.д.), которые автору в момент записи не нужны. HTML-страница даёт сфокусированный «съёмочный пульт».

**Когда предлагать создать:** **обязательно** после того как в `reels/production/YYYY-MM-DD.md` собрано 3+ Reel'а готовых к записи. Не ждать пока автор попросит — предложить самим в духе «давай соберу страницу для удобной записи».

**Не путать с `*-monaj.html` / `2026-05-01.html`** — та страница для **монтажёра** (с Google Drive ссылками, без кнопки копировать). Эта — для **автора на момент съёмки**.

**Что должно быть на странице:**

| Элемент | Зачем |
|---|---|
| Карточки на все Reels, свёрнутые `<details>` | компактный обзор |
| 📋 **Копировать в суфлёр** (главная кнопка) | хук + тело → буфер → вставить в Notes/Telegram |
| 🎤 **Развернуть для съёмки** | полноэкранный суфлёр-режим (шрифт 26-30px, чёрный фон, Esc закрывает) |
| ✓ **Отметить записанным** + сохранение в `localStorage` | прогресс по дню, не теряется при перезагрузке |
| Хук — отдельным блоком с пометкой «1 в 1, не менять» | напоминание правила |
| Текст для записи — крупным кеглем (18px+) | читается с расстояния |
| Заметки к записи | что показать в кадре, скриншоты, ремарки монтажу |
| CTA × 3 платформы (компактно) | проговорить нужный после хука |
| 🔗 Кнопка «открыть оригинал» в Instagram/YouTube | если нужно пересмотреть референс |
| 📜 Транскрипт оригинала (свёрнут) | для сверки если что-то непонятно в моём тексте |
| 📝 **Открыть .md в редакторе** через `vscode://file/...` | быстро поправить если на лету что-то меняешь |
| Фильтры all / wait / ok + живой поиск | удобство при 20+ Reels |
| Счётчики записано/на запись/всего | мотивация прогресса |

**Дизайн:** стиль «Крафтовый терминал» (тёмный фон `#1a1612`, акцент `#e8a04a`) — единообразие со всеми нашими страницами.

**Генератор:** `reels/tools/build_shooting_page.py` — парсит `2026-05-13.md` и собирает HTML. После любых правок в .md → запустить `python3 reels/tools/build_shooting_page.py` чтобы пересобрать.

**Эталон:** `reels/production/2026-05-13-shooting.html`.

**Технологии:** один самодостаточный HTML (без сборки, без зависимостей, ванильный JS, Clipboard API, localStorage, `vscode://` URL-схема). Открывается двойным кликом в Finder.
