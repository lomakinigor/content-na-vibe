# Скилл: Поиск трендов YouTube

## Когда использовать

Клиент говорит: «найди тренды», «что сейчас в топе», «какие темы стреляют», «проверь канал конкурента», «идеи по теме X», «какие ролики виральные», «покажи что работает в нише», «проверь эти URL на ratio».

Также активируется **из стартового меню** (когда пользователь в начале сессии выбирает **🔍 Поиск трендов**).

---

## Перед работой — собери бриф через `AskUserQuestion`

Не начинай поиск без полного контекста. Чеклист ниже — обязательный.

### Шаг 1: уточнить под-режим

Через `AskUserQuestion` предложить 3 варианта:

| Под-режим | Когда выбирать |
|-----------|-----------------|
| 🔎 По ключевым словам | «что стреляет в нише» — тематический срез рынка |
| 📺 Канал конкурента | «что работает у конкретного блогера» — разбор одного канала |
| 📋 Свой список URL | «проверь эти ролики» — верификация гипотез |

### Шаг 2: по выбранному под-режиму — доуточнить параметры

**🔎 По ключевым словам** — через `AskUserQuestion`:
1. **Ключевые слова / запрос** (текстом: «Claude Code tutorial», «вайбкодинг», итп)
2. **Регион**: RU / US / Worldwide
3. **Период**: 30 дней / 60 дней / 90 дней (по умолчанию — 30)
4. **Формат видео**: 🎬 Длинные (Recommended) / ⚡ Shorts / 🎭 Оба — см. раздел «Формат видео» ниже

**📺 Канал конкурента** — через `AskUserQuestion`:
1. **@handle канала** (например `@NickVels_AI`)
2. **Сколько последних видео** разобрать: 15 / 30 / 50
3. **Формат видео**: 🎬 Длинные (Recommended) / ⚡ Shorts / 🎭 Оба

**📋 Свой список URL** — текстом:
1. Путь к файлу `input/*.txt` с URL (по одному на строку) — или пусть пользователь скинет список, сохрани в `input/candidates-YYYY-MM-DD.txt`
2. **Формат видео**: 🎬 Длинные (Recommended) / ⚡ Shorts / 🎭 Оба

### 📺 Формат видео — обязательный пункт брифа

Канал автора — про **горизонтальные длинные видео**. По умолчанию исключай Shorts из всех поисков. Через `AskUserQuestion` предложи 3 опции:

| Label | Описание | CLI-флаг |
|-------|----------|----------|
| 🎬 Длинные (Recommended) | Только горизонтальные, >3 минут | `--exclude-shorts` |
| ⚡ Shorts | Только Shorts (≤3 минут), если нужна идея для вертикали | `--only-shorts` |
| 🎭 Оба | Смешанный поиск с пометкой Type в отчёте | _(без флага)_ |

Если пользователь не оговорил формат — применяй `--exclude-shorts` по умолчанию.

### Шаг 3: что делать с результатом

Финальный вопрос перед запуском — через `AskUserQuestion`:

| Опция | Что будет после отчёта |
|-------|------------------------|
| Только отчёт | Сгенерирую markdown, дальше ты сам решаешь |
| Отчёт + сценарий по ТОП-1 | После отчёта сразу переключаюсь в режим 💡 «Сценарий по идее» по самой виральной теме |

### Шаг 4: показать бриф и ждать подтверждения

Одним сообщением:

> Вот что понял:
> - Под-режим: …
> - Запрос/канал/файл: …
> - Регион: …, период: … дней, порог ratio: ≥5
> - После отчёта: …
>
> Запускаю?

Только после «да» — запускаешь CLI.

## Выполнение

### Команды

```bash
cd tools/trend-finder

# 🔎 По ключевым словам (дефолт — только длинные)
.venv/bin/python trend_finder.py --search "ЗАПРОС" --region RU --days 30 --min-ratio 5 --exclude-shorts

# 📺 Канал конкурента (дефолт — только длинные)
.venv/bin/python trend_finder.py --channel @handle --last 30 --exclude-shorts

# 📋 Список URL
.venv/bin/python trend_finder.py --urls input/candidates-YYYY-MM-DD.txt --min-ratio 5 --exclude-shorts

# Только Shorts (если пользователь явно выбрал)
.venv/bin/python trend_finder.py --search "ЗАПРОС" --region RU --days 30 --only-shorts --min-ratio 10

# Смешанный (оба формата с пометкой Type в отчёте)
.venv/bin/python trend_finder.py --search "ЗАПРОС" --region RU --days 30 --min-ratio 5

# Дополнительные флаги:
#   --min-views N       фильтр по минимальным просмотрам
#   --output PATH       кастомный путь отчёта (по умолчанию output/trends-YYYY-MM-DD.md)
```

### Обязательные флаги по умолчанию

- `--min-ratio 5` — порог сильного ролика в этой нише (см. калибровку ниже)
- `--days 30` — если пользователь не сказал иначе
- `--exclude-shorts` — **ВСЕГДА**, если пользователь не выбрал «⚡ Shorts» или «🎭 Оба»

### Как определяется Short

Эвристика: **видео ≤ 180 секунд** классифицируется как Short. Точность ~99% для обычного контента Claude Code / AI / вайбкодинг. У каждой записи в коде есть свойство `VideoRow.is_short` — его используем и в фильтре, и в колонке Type отчёта.

## ⚠️ Калибровка ratio (критично — не игнорировать)

Верифицировано 2026-04-19 через YouTube Data API на 25 URL + 3 поиска + разбор @NickVels_AI.

| Ratio (views / channel subs) | Оценка для ниши Claude Code / AI / вайбкодинг |
|------------------------------|------------------------------------------------|
| **×10+** | Явный вирус |
| **×5–10** | Сильный ролик |
| **<×3** | Органика (дошёл только до ядра канала) |

**НЕ применяй порог ×50** — в этой нише он нереалистичен. У эталонного @NickVels_AI топ-ролик ×9.1. Всегда фильтруй от `--min-ratio 5`.

## Формат итогового отчёта

CLI сам сохраняет markdown-таблицу в `tools/trend-finder/output/trends-YYYY-MM-DD.md`:

```markdown
| # | Title | Channel | Views | Subs | Ratio | V/h | Date | URL |
|---|-------|---------|-------|------|-------|-----|------|-----|
```

Сортировка — по ratio (убывание).

### Если надо свести в месячный отчёт

Объедини несколько прогонов в `research/trends-YYYY-MM.md` по шаблону существующего `research/trends-2026-04.md`:

- **Контекст** — дата, период, рынки, метрика
- **ТОП-10 тем** — каждая с: почему стреляет / референсы / угол подачи / сложность
- **Рекомендация ТОП-3** — что снимать первым
- **Раздел «Провалы»** — ролики с низким ratio, чтобы видеть антипаттерны

## После отчёта — обязательный мост

Всегда предлагай через `AskUserQuestion`:

> «Что дальше? Варианты:
> 1. Запускаем сценарий по ТОП-1 теме (режим 💡)
> 2. Возьмём ТОП-2 или ТОП-3 — какую выбираешь
> 3. Сохраняю отчёт и на сегодня всё»

Никогда не выходи из скилла молча — всегда показывай пользователю следующий шаг.
