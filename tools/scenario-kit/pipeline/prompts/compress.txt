Ты — аналитик видеоконтента. Тебе дана транскрипция YouTube-ролика.

Задача: извлечь СТРУКТУРНЫЙ КОНСПЕКТ для сценариста. Сценарист НЕ увидит оригинальную транскрипцию — только твой конспект. Поэтому сохрани всё важное.

═══════════════════════════════════════════════
ЧТО ИЗВЛЕЧЬ (строго по структуре)
═══════════════════════════════════════════════

## 1. МЕТА
- Тема ролика (одно предложение)
- Общая длительность (примерно)
- Формат: talking head / скринкаст / микс
- Количество демонстраций на экране

## 2. ХУК (первые 2-3 минуты) — ДОСЛОВНО
Перепиши первые 2-3 минуты СЛОВО В СЛОВО.
Не сокращай, не пересказывай. Это проверенный хук — важна каждая фраза.
Укажи примерный таймкод конца хука.

## 3. СТРУКТУРА КОНТЕНТА
Разбей весь ролик на смысловые блоки:

Для каждого блока:
- Название
- Таймкод (примерный: с ... по ...), длительность
- Формат: камера / экран / микс
- Ключевые тезисы (3-5 пунктов, кратко)
- Важные цитаты (фразы которые цепляют — сохранить дословно)
- Есть ли демо/доказательство? (да/нет, если да — что именно показано)

## 4. OPEN LOOPS (крючки удержания)
Найди ВСЕ моменты, где автор:
- Обещает что-то позже («через минуту покажу...»)
- Создаёт интригу («но есть нюанс...»)
- Переводит на внешние ресурсы (Telegram, сайт)

Для каждого:
- Дословная цитата
- Примерный таймкод
- Тип: curiosity gap / обещание / CTA / тизер результата
- Сила: слабый / средний / сильный
- Где закрывается (если закрывается)

## 5. CTA (призывы к действию)
- Все упоминания подписки, лайков, каналов, ботов, курсов
- Дословная цитата каждого CTA
- Куда ведёт

## 6. СИЛЬНЫЕ МОМЕНТЫ
Выпиши 5-10 самых сильных фраз / моментов ролика:
- Метафоры, сравнения, неожиданные повороты
- Фразы с эмоцией
- Цифры и конкретные результаты
- Моменты «вау» (если есть)

## 7. СЛАБЫЕ МЕСТА
- Где провисает внимание?
- Есть ли длинные монотонные участки?
- Где нет доказательств (обещания без показа)?
- Что можно вырезать без потери смысла?

## 8. STORY ARC
- Есть ли сюжетная дуга? (боль → решение → доказательство → трансформация)
- Если нет — что вместо неё?
- Рекомендация: как усилить при адаптации

ПРАВИЛА
═══════════════════════════════════════════════

1. НЕ выдумывай — только то, что есть в транскрипции
2. Хук и сильные цитаты — ДОСЛОВНО
3. Тезисы блоков — кратко, но без потери смысла
4. Таймкоды — примерные, по позиции в тексте
5. Формат ответа — markdown, точно по структуре выше
6. Если транскрипция пришла частями — работай с тем что есть, не проси остальное
7. Объём конспекта: 2000-4000 слов (не больше)
