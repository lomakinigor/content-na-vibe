1. Через бота @Iitrans_bot — команда /scenario (по видео или по теме)
2. Через агента напрямую — «сделай сценарий на тему X» или «разбери этот ролик»

## Уроки из аудита (апрель 2026)

Первый сценарий (claude-luchshaya-nejroset v1) получил 5/10. Проблемы:

### 1. Фича-тур вместо истории
**Было:** Блок за блоком — проекты, skills, style, артефакты, сценарии.
**Стало:** Story arc — боль → решение → живое демо → трансформация.
**Правило:** Каждый сценарий = история. Линейный обзор функций запрещён.

### 2. Слабые open loops
**Было:** «Промпты выложу в Telegram» (это CTA, не крючок), «Покажу на экране» (нет stakes).
**Стало:** «Есть один нюанс, из-за которого 90% бросают...» (curiosity gap).
**Правило:** Open loop должен мучить зрителя. Тест: убери его — если ничего не изменится, он слабый.

### 3. Нет живой демонстрации
**Было:** «Один промпт — готовый пост» (обещание без доказательства).
**Стало:** Два блока демо (пост + анализ ЦА) = 7 мин из 16.
**П��авило:** Минимум 1 демо-блок = 30-40% хронометража. Show, don't tell.

### 4. Отдельный блок «минусы» убивал энергию
**Было:** 4 минуса подряд перед CTA → зритель уходит на демотивации.
**Стало:** Минусы вплетены в контент: VPN — в хуке, лимиты — в финале с решением.
**Правило:** Нет отдельного блока «подводные камни». Минус + решение = внутри контента.

### 5. Плоский финал
**Было:** Сухой CTA — подпишись, лайк, Telegram (×3).
**Стало:** Итог-результат → философия («возвращает время») → одна ссылка → open loop.
**Правило:** Финал = эмоциональная кульминация. Воронку упоминать не более 2 раз за ролик.

### 6. Не было retention-проверки
**Было:** Блоки шли подряд без вопроса «а зритель ещё здесь?».
**Стало:** Каждый блок проверяется: «почему зритель НЕ переключит?».
**Правило:** Между 5 и 8 минутой — обязательно визуальное (демо, скринкаст).

## Результат
v1: 5/10 → v2: 7/10. Все правила закодированы в промптах и SKILL.md.

## Формат сценария (быстрая справка)
- Шпаргалка для съёмки БЕЗ суфлёра
- 4-5 опорных точек в хуке
- Хронометраж у каждого блока + пометка [камера/экран]
- Open loops — фразы с curiosity gap, указать где закрывается
- Переходы между блоками
- ⚠ Пометки где адаптировать
- Стиль из knowledge/writing-style.md
- Пол: мужской
