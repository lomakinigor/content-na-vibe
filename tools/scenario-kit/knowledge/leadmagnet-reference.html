Устанавливаем инструменты

VS Code + Claude Code — всё что нужно для начала
Метафора VS Code — это как столярная мастерская: внутри можно работать с любым инструментом. Мы берём один — Claude Code. Это как нанять программиста, который живёт в твоём компьютере. Говоришь ему что сделать на русском — он делает. Зарплату не просит.
  1. Скачай VS Code — нажми кнопку ниже, выбери Windows или Mac, установи как обычную программу
  2. Открой VS Code. Слева найди иконку с четырьмя квадратами — это магазин расширений (как App Store)
  3. В строке поиска напечатай Claude Code. Найди расширение от Anthropic → нажми Install
  4. После установки внизу экрана появится чат с Claude. Войди в аккаунт Anthropic
↓ Скачать VS Code ↓ Установить Claude Code
Важно: VS Code бесплатный. Claude Code — платный (есть пробный период). Нам нужен именно Claude Code в VS Code, а не обычный Claude в браузере — только он умеет создавать файлы и писать код на твоём компьютере.

Формулируем идею

Четыре вопроса — и у тебя готовое ТЗ

Любой продукт начинается с идеи. Перед созданием нужно ответить на 4 вопроса и зафиксировать их в файле — Claude будет использовать этот файл на всех следующих шагах.

Метафора Это как перед ремонтом квартиры ответить: что именно хочу сделать, зачем, какая сейчас проблема, и что изменится когда всё готово. Без этого строители будут переделывать по три раза.
Промпт 1 — Описание идеи
Помоги мне сформулировать идею для AI-агента. Ответь на 4 вопроса и запиши результат в файл specification.md: 1. Что я хочу собрать? (опиши в одном предложении что за продукт) 2. Как это создать? (Telegram-бот / веб-приложение / что-то другое) 3. Какую проблему это решает? (какую боль убирает у пользователя) 4. Какой результат получу? (что изменится после внедрения) После того как ответим на эти вопросы — создай файл specification.md и запиши туда нашу идею. Этот файл понадобится на следующих шагах.
  1. Открой Claude Code в VS Code (чат внизу или сбоку экрана)
  2. Скопируй промпт выше и вставь в чат
  3. Отвечай на вопросы — например: «хочу бота для записи клиентов в барбершоп»
  4. Claude создаст файл specification.md — он понадобится на следующих шагах
Из видео: автор выбрал бота-консультанта для зала единоборств. Проблема — владелец постоянно отвечал на одни вопросы про расписание, цены и запись. После — бот отвечает сам, владелец тренирует людей, заявок стало вдвое больше.

Исследуем рынок

Запускаем AI-агентов в интернет — они найдут лучшие идеи
Метафора Раньше маркетолог неделю вручную изучал конкурентов — открывал вкладку за вкладкой. Теперь отправляешь несколько AI-агентов с разными задачами. За 3 минуты они изучат сотни сайтов и принесут 5 лучших идей. Ты просто ждёшь.
Промпт 2 — Исследование рынка
Вот мой файл спецификации (specification.md). Проведи мне хорошее исследование рынка. Запусти несколько агентов в интернет. Пусть они посмотрят на форумах, на GitHub, на IT-стартапах — что уже реализовано. Глубоко не копай. Твоя задача: зайти и сравнить что есть на рынке относительно моей идеи. Принеси мне 5 самых сильных идей которые я могу добавить себе. Например: - Какие кнопки должны быть в боте - Как правильно построить AI-модуль - Какие фишки точно усилят мой продукт Приведи исследование и дай заключение простым языком.
  1. Отправь промпт в тот же чат Claude Code
  2. На экране видишь как агенты работают — GitHub, форумы, стартапы
  3. Через 3–5 минут возвращаются с результатами
  4. Claude делает выжимку: 5 лучших идей для твоего продукта
Совет: Пока агенты работают — налей кофе. Это реально 3–5 минут. Не торопи.
Из видео: Для бота спортзала нашли: квалификационные вопросы вместо простого приветствия, пошаговая запись через кнопку «Поделиться контактом», цепочка автонапоминаний. автор сам до этого не додумался — интернет принёс готовые идеи.

Создаём план разработки

Claude составит план ДО того как начнёт писать код
Метафора Это как попросить строителя: сначала покажи мне что и в каком порядке будешь делать — потом начинай. Тогда он идёт по плану, отмечает что сделал, и меньше ошибается.
Промпт 4 — План разработки
Создай пошаговый план для разработки этого бота, опираясь на спецификацию (specification.md). Сначала пришли мне этот план здесь в чате — прежде чем начнёшь разрабатывать. После того как я одобрю план — сохрани его в отдельный файл plan.md. Когда будешь выполнять работы — отмечай галочкой какой шаг уже выполнил.
Почему это важно: На этом этапе могут появиться новые идеи — добавь их прямо сейчас. Скажи Claude: «Добавь ещё вот это». Лучше сейчас, чем переделывать потом когда код уже написан.

Промпт 5 — Разработка бота

Когда тебе понадобится что-то от меня (токен бота, API ключ, ID) — скажи мне об этом и объясни где это взять.

Создаём бота в Telegram

BotFather выдаст токен — официальный пропуск для твоего бота
Метафора BotFather — это как паспортный стол для ботов. Приходишь, называешь имя — тебе выдают официальный документ (токен). Без него бот не сможет работать в Telegram.
  1. Открой Telegram и найди бота @BotFather — с синей галочкой (это официальный)
  2. Нажми Start и напиши команду: /newbot
  3. BotFather спросит имя бота — напиши любое: «Помощник Марины» или «Консультант кафе»
  4. Потом спросит username — адрес бота. Должен оканчиваться на bot. Например: marina_helper_bot
  5. BotFather пришлёт токен — длинная строка. Скопируй и передай Claude в VS Code
Открыть BotFather в Telegram
Осторожно: Токен — это как пароль. Никому не показывай и не публикуй публично. Если засветил — создай новый через команду /token у BotFather.
Также понадобится твой Telegram ID: Claude попросит числовой ID (это не username). Найди в Telegram бота @userinfobot, напиши ему /start — он пришлёт твой ID. Скопируй и передай Claude.

Подключаем AI через OpenRouter

Получаем ключ — чтобы бот умел думать и отвечать на вопросы
Метафора OpenRouter — это маркетплейс AI-мозгов. Как магазин, где берёшь напрокат интеллект разных нейросетей. Платишь только за использование. API ключ — это твоя карточка покупателя.
  1. Открой сайт openrouter.ai и зарегистрируйся через Google или email
  2. В левом меню найди раздел API Keys
  3. Нажми кнопку Create Key
  4. Введи любое название (например: my-bot), период — No expiration
  5. Нажми Create — ключ появится на экране. Сразу скопируй — потом не увидишь!
  6. Вернись в VS Code и передай ключ Claude — он положит его в файл .env (это как сейф)
Открыть OpenRouter
Бюджет: Пополни на $5 для начала — хватит на несколько месяцев тестирования.

Промпт 6 — Улучшение бота
Посмотри на этого бота глазами человека который видит его впервые. Он только что нажал /start. Что он видит? Что ему непонятно? Где может застрять? Предложи план как сделать бота лучше. Что добавить чтобы человек смог: — понять что это за бот и что он умеет — дойти от /start до целевого действия (запись / заявка / вопрос) — не потеряться и не запутаться

Примеры правок из видео

  • «Добавь после ответа кнопки, чтобы не нужно было возвращаться в меню»
  • «Добавь приветственное сообщение — чтобы бот представился и объяснил что умеет»
  • «Запоминай имя клиента и обращайся к нему по имени в ответах»
Это и есть вайбкодинг: Три правки — три минуты. Хочешь добавить платежи — говоришь. Голосовой режим — говоришь. Напоминания — говоришь. Claude делает.

Если что-то не работает

Самые частые ситуации и как их решить
Бот не отвечает в Telegram
Скорее всего сервер не запущен. Вернись в VS Code и напиши Claude: «Как запустить бота?». Он даст точную команду для твоего проекта.
Claude Code не видит мои файлы
Убедись что открыл нужную папку через File → Open Folder. Claude Code работает только с файлами текущей открытой папки.
OpenRouter пишет ошибку об оплате
Нужно пополнить баланс. Минимум $5 — хватит на несколько месяцев. Зайди в openrouter.ai → Settings → Credits.
BotFather не принимает username
Username должен оканчиваться на «bot» и быть уникальным. Попробуй добавить цифры или город: marina2024_bot, cafe_msk_bot, fitness_spb_bot.
Бот готов — что дальше?
Ты только что сделал то, за что программисты берут от 30 000 ₽. Без кода. Голосом. За один день.
