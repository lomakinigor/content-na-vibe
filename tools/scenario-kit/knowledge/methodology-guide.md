# Гайдлайн: Как создавать YouTube-методичку

> Этот документ — инструкция для агента. Прочитай его целиком перед созданием любой методички.

---

## Что такое методичка и для кого

**Методичка** — интерактивный HTML-файл. Зритель смотрит видео, потом открывает методичку и повторяет шаги сам.

**Главная цель читателя:** знать что делать дальше после каждого шага. Не обязательно дойти до конца за один раз — но всегда понимать следующий шаг.

**Аудитория:** не-программисты. Люди, которые не знают что такое API, токен, ENV-файл, bash. Объяснять всё как другу — через метафоры из жизни.

---

## Шаг 0: Что читать перед созданием

**ОБЯЗАТЕЛЬНО** прочитать ВСЕ файлы из папки ролика `scripts/{slug}/`:

| Файл | Зачем |
|------|-------|
| `transcript.txt` | Полная хронология видео — откуда брать реальные слова и промпты |
| `ready-for-filming/{slug}.md` | Сценарий с блоками и опорными точками — структура и промпты |
| `promises-analysis.md` | Что обещал, какие сервисы упомянул, ссылки |
| `postproduction/content/summary.md` | Конспект — ключевые идеи |

---

## Шаг 1: Определить структуру

Структура методички = хронология видео. **Не придумывай структуру из головы.**

Алгоритм:
1. Прочитай транскрипцию → найди ключевые моменты (когда переходит к новому действию)
2. Прочитай сценарий → возьми блоки как основу разделов
3. Каждый блок видео = один шаг методички

**Правило:** если в видео 7 смысловых блоков — в методичке 7 шагов. Нумерация с 0 (нулевой шаг — установка/подготовка).

### Типичная структура для практических видео:
```
Шаг 0: Подготовка (установка инструментов)
Шаг 1: [Первое действие из видео]
Шаг 2: [Второе действие]
...
Шаг N: Тест / результат
Чек-лист
Секция "Если что-то не работает"
Footer с CTA
```

## Шаг 2: Правила написания контента

### Язык
- Разговорный, как объяснение другу. Не как документация.
- Никаких технических терминов без немедленного объяснения.
- Пример плохо: «Создайте ENV-переменную»
- Пример хорошо: «Создадим файл .env — это как сейф, где хранятся секретные ключи»

### Метафора-блок (обязательный элемент в каждом шаге)
Перед действиями — **одна метафора** из реальной жизни. Объясняет зачем и что это такое.

Формат:
```
VS Code — это как столярная мастерская. В ней есть любой инструмент. 
Мы берём один — Claude Code. Это как нанять программиста, который живёт в компьютере.
```

### Промпты
- Берутся из транскрипции (реальные слова из видео) или сценария
- Адаптируются для читателя (не голосовые, а письменные)
- Каждый промпт — в отдельном блоке с кнопкой «Скопировать»
- Промпт должен быть самодостаточным (читатель вставляет в Claude Code и получает результат)

### Ссылки
- Каждый упомянутый инструмент = рабочая кликабельная ссылка
- К каждой ссылке — инструкция: что именно делать на этой странице
- Минимум: VS Code, Claude Code (marketplace), OpenRouter, BotFather

### Пошаговые инструкции
Формат numbered list с деталями:
```
1. Открой сайт openrouter.ai → зарегистрируйся через Google
2. В левом меню найди раздел API Keys
3. Нажми Create Key → введи любое название
4. Скопируй ключ СРАЗУ (он показывается только один раз!)
```

## Шаг 3: Дизайн и HTML-структура

### Общий стиль — «Крафтовый терминал» (единый стандарт, утверждён автором 2026-07-02)
- Светлый пергаментный фон `#F5E6D0`, текст графит `#1E1E1E`, главный акцент терракот `#E8762B`
- Зелёный `#7A8C3A` — чек-листы/успех, золото `#B8841A` — метафоры/инсайты
- Код-блоки ТЁМНЫЕ (графит `#1E1E1E`/`#2D2D2D`, текст `#EDEDED`) с кнопками «Копировать»/«Скачать»
- Scroll-based (без табов, всё на одной странице)
- Progress bar вверху (sticky, обновляется по чек-листу)
- Numbered sections с anchor-ссылками
- Google Fonts: Oswald 700 (заголовки, КАПС), Inter (тело), JetBrains Mono (код/промпты/лейблы/кнопки)

### Обязательные компоненты каждого шага:
```html
<section id="sN">
  <!-- Номер + заголовок -->
  <div class="section-header">
    <div class="section-num">N</div>
    <h2>Название шага</h2>
  </div>
  
  <!-- Метафора-блок (ОБЯЗАТЕЛЬНО) -->
  <div class="metaphor">...</div>
  
  <!-- Пошаговые действия -->
  <ol class="action-list">...</ol>
  
  <!-- Промпт (если есть в этом шаге) -->
  <div class="prompt-block">
    <div class="prompt-header">
      <span>Промпт N — Название</span>
      <button onclick="copyPrompt(this)">Скопировать</button>
    </div>
    <div class="prompt-text">...</div>
  </div>
  
  <!-- Кликабельные ссылки -->
  <a class="link-btn primary" href="...">Название сервиса</a>
  
  <!-- Tip или Warning (если нужно) -->
  <div class="tip">💡 ...</div>
  <div class="tip warning">⚠️ ...</div>
  
  <!-- Callout "Пример из видео" (опционально) -->
  <div class="callout">...</div>
</section>
```

### Чек-лист
- В конце всех шагов — интерактивный чек-лист
- Пункт для каждого значимого действия (не для каждого шага)
- Сохранение состояния в localStorage
- Progress bar обновляется от чек-листа

### Footer CTA
- Написать текст CTA специально под это видео (не шаблонный)
- Ссылки: Telegram (@example), YouTube, Instagram* (со звёздочкой), Воронка практикума
- **ВСЕГДА спрашивать у пользователя** перед публикацией: «Какие ссылки добавляем — все четыре или часть?»
- Disclaimer: `* Meta Platforms Inc. признана экстремистской организацией на территории РФ`

## Шаг 4: Что НЕ делать

❌ Не выдумывать шаги которых не было в видео  
❌ Не писать «используй Claude Code» без конкретного промпта  
❌ Не упоминать инструмент без ссылки куда идти  
❌ Не использовать технические термины без объяснения простым языком  
❌ Не делать табы — только scroll  
❌ Не вставлять ссылки на Python docs, aiogram docs, Render — если не было в видео явно  
❌ Не копировать структуру из головы — только из транскрипции  

---

## Шаг 5: Проверка перед сохранением

- [ ] Шаги идут в том же порядке что в видео
- [ ] У каждого шага есть метафора
- [ ] У каждого шага с промптом — кнопка «Скопировать»
- [ ] Все упомянутые инструменты имеют рабочие ссылки
- [ ] Факт-чек: цифры, цены, названия и свойства инструментов взяты из видео/транскрипции или помечены [УТОЧНИТЬ]
- [ ] Язык простой — нет необъяснённых технических терминов
- [ ] Чек-лист работает и сохраняется в localStorage
- [ ] Progress bar обновляется
- [ ] Footer со ссылками согласован с пользователем

## Технические детали

### Где сохранять
```
scripts/{slug}/postproduction/content/Методичка.html
```

### JavaScript-функции (обязательные)
```javascript
// Копирование промпта
function copyPrompt(btn) {
  const text = btn.closest('.prompt-block').querySelector('.prompt-text').textContent;
  navigator.clipboard.writeText(text.trim()).then(() => {
    btn.textContent = 'Скопировано!';
    setTimeout(() => { btn.textContent = 'Скопировать'; }, 2000);
  });
}

// Чек-лист с localStorage
function toggleCheck(li) {
  li.classList.toggle('done');
  localStorage.setItem('check_' + li.dataset.id, li.classList.contains('done') ? '1' : '0');
  updateProgress();
}

// Восстановление состояния
document.querySelectorAll('#checklist li').forEach(li => {
  if (localStorage.getItem('check_' + li.dataset.id) === '1') li.classList.add('done');
});
updateProgress();
```

## Эталонный дизайн-шаблон

Эталон — лид-магнит «Claude Code бесплатно» в дизайне «Крафтовый терминал» (утверждён автором навсегда):
```
scripts/✅ claude-code-besplatno/lead-magnet/guide.html
```

Используй его как **референс стиля**: структуру секций (заголовок → метафора → инструкции → код → чек-лист → раскрывашка «подробнее»), типографику, callout-блоки, тёмные code-blocks с кнопками, футер с CTA-кнопками. Палитра и шрифты — брендбук `design/README.md`.

Для методичек на Vercel (`methodology-app/`) те же токены уже зашиты в `src/index.css` — там структуру задаёт data-файл, CSS не трогать.
Отличие YouTube-методичек: нет фиксированного левого сайдбара (только scroll + progress bar наверху).

## Когда создавать методичку

Методичка создаётся на **этапе Postproduction** — после транскрибации и анализа обещаний.

Вызов: пользователь говорит «создай методичку», «сделай шпаргалку», «методичка для видео».

Агент спрашивает (если не указано):
1. «Для какого ролика?» (slug)
2. Читает все файлы из `scripts/{slug}/`
3. «Какие ссылки в футере — все четыре или часть?»
4. Создаёт и сохраняет файл
