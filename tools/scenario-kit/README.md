# YouTube Scenario Kit

Полный набор файлов для создания сценариев видео.

## Структура

```
prompts/
  scenario.txt          — промпт для генерации сценария ПО ВИДЕО (из транскрипции)
  scenario_topic.txt    — промпт для генерации сценария ПО ТЕМЕ (с нуля)

skills/
  SKILL.md              — скилл для Claude Code (инструкция агенту)

knowledge/
  writing-style.md      — стиль автора: тон, паттерны, метафоры, табу
  post-structure.md     — формулы структуры: два регистра, ключевые слова
  feedback_scenario_skill.md — заметки по работе со сценариями

renderer/
  scenario_renderer.py  — Python-рендерер сценария (из транскрибатор-бота)

examples/
  scenario-ai-agent-v2.md       — пример сценария (markdown)
  scenario-ai-agent-live-v2.html — пример сценария (HTML с таймером)
```

## Как использовать

### В Claude Code (локально)
1. Скопируй `skills/SKILL.md` → `.claude/skills/youtube-scenario/SKILL.md`
2. Скопируй `knowledge/` → в корень проекта или `knowledge/`
3. Скопируй `prompts/` → куда удобно, обнови пути в SKILL.md
4. Скажи: «сделай сценарий на тему X» или «разбери этот ролик»

### Формат сценария (каждый блок)
- Ключевые смыслы — что ОБЯЗАТЕЛЬНО сказать
- Опорные точки — порядок мыслей
- 🪝 Open Loop — фраза + куда ведёт (канал/курс/бот)
- 🔗 Переход — связующая фраза к следующему блоку
- ⚠ Адаптировать — что заменить на своё
