# CLAUDE.md — как собирать navigator.html

Этот файл читает AI-агент, когда клиент просит презентацию к ролику. Определяет стандарт **презентации-навигатора** формата 1 (веб-гид: сайдбар-оглавление + блоки).

## Что это

`navigator.html` — переносной HTML-гид по ролику. Слева оглавление-меню, справа блоки контента (метафора + терминал + карточки боль/выигрыш/когда). Клиент открывает его при записи как шпаргалку-структуру и может отдать зрителям или вложить в описание.

**Это НЕ слайды-презентация и НЕ вариант со шпаргалкой 75/25.** Реплики для чтения — отдельный файл-суфлёр.

## Что у тебя есть

| Файл | Назначение |
|---|---|
| `navigator-template.html` | **Канонический эталон.** Копируй `<style>` и `<script>` целиком, меняй только контент секций |
| `navigator-guide.md` | Полная методичка: формат блока, дизайн-система, как раскладывать тему, чек-лист |

## Алгоритм «собери презентацию»

1. **Прочитай** `navigator-template.html` и `navigator-guide.md`.
2. **Возьми готовый сценарий** (от `scenario-writer`) — блоки навигатора берутся из него, не выдумываются.
3. **Прочитай голос клиента** `~/packages/content-na-vibe/voice/author-voice.md` — весь текст пиши его тоном.
4. **Скопируй `<style>` и `<script>`** из эталона без изменений.
5. **Собери блоки** по формуле (см. гайд): intro → 7±2 блока (номер + заголовок КАПС + метафора + терминал + карточки pain/win/note) → «с чего начать».
6. **Синхронизируй сайдбар** — пункты меню = `id` блоков.
7. Пройди чек-лист из гайда, покажи клиенту.

## Жёсткие правила

**Дизайн (не менять):** палитра «Крафтовый терминал» (пергамент/терракот/графит + pain/win/note), шрифты Oswald / Press Start 2P / Inter / JetBrains Mono. Никаких других цветов, градиентов, фиолетового/неона.

**Структура (соблюдай):**
- Каждый блок = `<section>` с `min-height:100vh` и `scroll-snap-align:start`.
- Блок строится по паттерну: `.block-header` (пиксельный номер + `<h2>` КАПС) → `.metaphor` (бытовая метафора, обязательна) → `.terminal` (команды, если есть) → карточки `.card.pain` → `.card.win` → `.card.note`.
- Первый блок — `.intro-section` (заголовок ролика + обещание). Последний — «С чего начать» (win-карточки).

**Запрещено класть в навигатор:** open loops («сейчас покажу…»), тайминги съёмки, метки камера/экран, пометки ведущему. Всё это — в суфлёр.

**Технически:** никаких inline-стилей (только классы), не переписывай CSS из эталона, голос клиента вместо шаблонных фраз.

## Если просят другой стиль/цвета

Палитра «Крафтовый терминал» — бренд-стандарт. Менять только по явному запросу клиента с предупреждением, что это отступление от стандарта.
