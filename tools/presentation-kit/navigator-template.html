7 скрытых фишек Claude Code

Работай с Claude в 3-5 раз быстрее. Перестань упираться в лимит, терять диалоги и бояться, что он сломает файл.

01

Plan mode — план перед работой

Как прораб: сначала чертёж, потом стройка
Shift + Tab — два раза, вкл / выкл
plan mode on — индикатор в углу
Claude кидается делать сразу — не туда. Сломал полчаса работы.
Сначала видишь план. Правишь формулировку. Только потом работа. Ноль сюрпризов.
Когда: сложная задача, рефакторинг, страшно сломать важный файл.
02

Критерии проверки — самопроверка в конце

Как «привези пиццу и пришли фото, что доставил»
  • ...запусти и покажи результат
  • ...проверь, что импорты работают
  • ...прогони тесты, если красные — исправь
  • ...открой файл и убедись, что JSON валидный
Claude говорит «готово», а оно не работает. 3 итерации вместо одной.
В 2 раза меньше итераций. Claude сам чинит свои ошибки.
Когда: ВСЕГДА. Привычка: каждая задача заканчивается словом «проверь».
03

Session History — диалоги не теряются

Как WhatsApp: закрыл, открыл — всё на месте
Значок Claude Code слева в VS Code
→ вкладка History
→ список всех разговоров: дата, время, превью
Закрыл вкладку → думаешь, диалог пропал. Полчаса объяснений насмарку.
Вчерашний разговор открывается одним кликом — продолжаешь с того же места.
Нюанс: история привязана к рабочей папке. Другая папка — другие сессии.
04

Гигиена контекста — лимит не проблема

Как рабочий стол: утром чистый, к вечеру завален
  • /clear — всё стереть, как новый чат
  • /compact — сжать диалог, сохранить суть
  • /compact сохрани [что именно] — сжать с фокусом
Индикатор: кружок с процентом в углу. 70% — пора жать /compact.
Claude тупит, упирается в лимит за час работы.
Работаешь весь день. Свежий контекст = лучший контекст.
Правило: новая задача — новый разговор через /clear.
05

Rewind — машина времени

Как сейв в игре: накосячил — загрузился, ничего не было
  • Esc + Esc — открывается меню истории
  • ↑ ↓ — выбрать точку отката
  • Enter — откатить только диалог
  • Ctrl+Enter — откатить диалог + файлы
Откатывается и переписка, и все правки файлов. Как Ctrl+Z в Word — только для всего проекта сразу.
Claude сломал файл — страшно экспериментировать.
Смелые эксперименты без риска. Не получилось — откатил.
06

CLAUDE.md — правила дома для Claude

Повесил на стену — все соблюдают
CLAUDE.md — файл в корне проекта
→ Claude читает его каждый раз
→ правила становятся законом
Три правила, которые стоит добавить:
  • «Оспаривай мои решения» — если мой подход плохой, скажи прямо. Не соглашайся просто потому, что я так сказал.
  • «Структура ответа» — каждый ответ: что сделано / что нужно от меня / следующие шаги.
  • «Предлагай улучшения» — после задачи подскажи, что автоматизировать или оптимизировать.
Повторяешь одно и то же в каждом диалоге.
Claude из подхалима становится личным советником.
07

Skills — готовые макросы

Как горячие клавиши в Word: один раз настроил, каждый день экономят
Skill — папка с инструкцией
→ Claude читает и действует по алгоритму
→ одна команда запускает весь процесс
Пример — Discovery Interview:
От расплывчатой идеи → к готовому техзаданию за 12 вопросов. Одна команда → Claude ведёт тебя по шагам → выдаёт структурированный документ.
Каждый раз объясняю Claude одно и то же.
15 минут объяснений → 1 команда и пошло.
★

С чего начать

Три главные вещи. Остальное осваивай постепенно.

1 — Критерии проверки. Привычка «проверь» в конце каждого запроса.
2 — CLAUDE.md правила. Три правила: оспаривай / структура / предлагай улучшения.
3 — /clear. Новая задача = новый разговор.

Если зайдёт хотя бы 3 фишки — ты уже сильно впереди.
