# Как собрать navigator.html (презентация-навигатор)

Стандарт презентации-навигатора для ролика. Это **веб-гид**: слева оглавление-меню, справа блоки контента. Клиент открывает его при записи (шпаргалка-структура) и может отдать зрителям/в описание.

**Канонический эталон — рядом: [`navigator-template.html`](navigator-template.html).** Копируй из него блок `<style>` и `<script>` целиком, меняй только контент. Не переписывай дизайн заново.

## Формат (не путать с презентацией-слайдами)

- **Двухколоночный макет:** слева `.sidebar` (графит, sticky) — название + `@канал` + список блоков (номер + эмодзи + название) + подсказка навигации. Справа `.main` — блоки, каждый на весь экран (`section`, `min-height:100vh`, `scroll-snap-align:start`).
- Не полноэкранные слайды-презентация. Не 75/25 со шпаргалкой. Реплики ведущего живут в отдельном файле-суфлёре, не здесь.

## Дизайн-система «Крафтовый терминал» (из эталона, не менять)

```css
--parchment: #F5E6D0;   /* фон */
--terracotta: #E8762B;  /* акцент */
--graphite: #1E1E1E;    /* сайдбар, терминал, текст */
--pain: #C84B3A;        /* карточка боли */
--win: #7A8C3A;         /* карточка выигрыша */
--note: #1E1E1E;        /* карточка «когда/нюанс» */
```

**Шрифты (Google Fonts):** `Oswald` 700 — заголовки блоков КАПС; `Press Start 2P` — пиксельные номера блоков и теги; `Inter` — основной текст; `JetBrains Mono` — команды и код.

## Структура одного блока (жёсткий паттерн)

Каждый `section` строится по формуле:

1. **`.block-header`** — пиксельный `.block-num` (00, 01…07 или ★) + `<h2>` заголовок блока КАПС.
2. **`.metaphor`** — одна бытовая метафора курсивом в терракотовой плашке («как прораб: сначала чертёж, потом стройка»). Обязательна.
3. **`.terminal`** — карточка-терминал (три точки macOS) с командами/действиями. `cmd` — терракот, `dim` — серые пояснения, `kbd` — клавиши. Если у блока нет команд — можно опустить.
4. **Карточки** в порядке:
   - `.card.pain` (красная полоса) — боль/проблема как есть сейчас.
   - `.card.win` (зелёная) — что получаешь с этой фишкой.
   - `.card.note` (графит) — когда применять / нюанс / правило.

Первый блок — `.intro-section` (центрированный): номер 00 + заголовок ролика + короткий текст-обещание.
Последний блок — «С чего начать» (★): 2-3 `.card.win` с главными шагами + финальная фраза.

## Как раскладывать тему на блоки

- **Story arc, не список фич:** БОЛЬ → РЕШЕНИЕ → ДОКАЗАТЕЛЬСТВО → ТРАНСФОРМАЦИЯ. Каждый блок = одна фишка/идея, которая закрывает конкретную боль зрителя.
- Обычно **7±2 блока** + intro + «с чего начать».
- Блоки берутся из сценария (`scenario.md`), не выдумываются. Название блока = суть фишки человеческим языком.
- Метафора обязательна в каждом блоке — бытовой образ, а не жаргон.
- Язык — голосом клиента (`voice/author-voice.md`), разговорный, без канцелярита.

## Навигация (из эталона, `<script>` копируется)

- `IntersectionObserver` подсвечивает активный пункт в сайдбаре при прокрутке.
- Клик по пункту — плавный скролл к блоку.
- Стрелки `↑`/`↓` листают блоки.

## Чек-лист перед выдачей

- [ ] Скопирован `<style>` и `<script>` из `navigator-template.html` без правок дизайна.
- [ ] Заменены: `<title>`, название и `@канал` в сайдбаре, пункты `nav`, контент `section`-ов.
- [ ] У каждого блока: пиксельный номер + заголовок КАПС + метафора + (терминал) + карточки pain/win/note.
- [ ] intro-блок и «с чего начать» на месте.
- [ ] Пункты сайдбара совпадают с `id` блоков (навигация работает).
- [ ] Никаких open loops, таймингов съёмки, меток камера/экран — это в суфлёре.
- [ ] Голос клиента, а не шаблонный текст.
- [ ] Открыть в браузере, проверить подсветку сайдбара и стрелки.
